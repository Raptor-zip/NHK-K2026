# TR 組立手順書

`cad/out/tr_match.step` を見ながら、この順で組む。工程ごとに **必ず確認する寸法** を書いてある。
ここを外すと後戻りが大きい箇所には ⚠ を付けた。

締付トルクは全工程共通で **M3: 1.2 / M4: 2.8 / M5: 5.0 N·m**（トルクレンチで管理）。
アルミフレームの締結は「ボルトが折れる前にポストナットが溝を滑る」ので、
**トルク管理そのものが安全機構**である（根拠は `scripts/fasteners.py`）。

材質は STEP の色で判別できる（**ピンク = 3Dプリント**、明るい銀 = 切削板、
くすんだ銀 = アルミフレーム、青銀 = SUS、濃灰 = スチール、水色 = ポリカ）。

## 工程 0. 事前準備（部材受入れ）

1. `BOM.md` の切断リストと現物を突き合わせる（**30本 / 16.61m**、
   うち HFS5-2010 が 2 本）。
   MISUMI 指定長は公差 ±0.5mm。**長さの実測をラベルに書いて貼る**（後工程の取り違え防止）。
2. 3Dプリント部品を出力する。ピンク色の部品がそれ。
   - 射出ローラーのハブ ×10（φ84×20、6穴スポーク）
   - 分離ローラーのハブ ×5（φ34×30、φ7 の穴を PCD22 に5つ）
   - シンギュレータのモーター取付金具 ×1（t3 の L 字、φ12 の軸穴 + 4-φ3.4 PCD26）
   - ニップ入口ガイド ×6（40×200×t2 + 継ぎ耳 t4×16、**3分割してあるのでベッド250mm級で刷れる**）
     板を寝かせて刷る。耳は板の面から立つので、サポート無しでそのまま出る。
   - カムフォロア ×1
   - バケツ押さえリング ×1（φ222 の輪 t4。皿ざぐり 4 か所。バケツの中に入る）
   - バケツ位置決めタブ ×4（`bucket_tab_0.stl` を 4 個刷る。0/1/2/3 は同じ形を
     90° ずつ回して置いたもので、**STL は 4 つとも同じ**）
   充填率 40%・肉厚 1.6mm 以上。ローラーハブだけは**真円度が命**なので、
   造形後に φ12 の穴をリーマ通しする。
   ⚠ タブの内面はバケツの胴に 0.3mm で沿うテーパー面。**寸法が出るように
   刷ること**（積層のダレで内側へ膨らむとバケツが入らない）。入らなければ
   内面を軽く削る側で合わせる（受け板の穴位置は変えない）。
3. 切削板を加工する。**モーターマウント板の φ16.7 インロー座は H8 公差**で。
   ここが緩いと車輪が振れる。
   ⚠ **φ26 ではない。** DJI 公式 CAD で実測した結果、取付面から突き出る
   インローは **φ16.7 × 高さ1.0mm** だった（φ26 は取付面より**内側**のボス）。
   φ26 で座ぐると 9.3mm ガバガバになり位置決めが効かない。
   軸は φ10 が取付面から **24.8mm** 突き出る（板厚 5mm なら裏に 19.8mm 出る）。
   → 根拠は `scripts/motor_check.py` と `cad/vendor/dji/README.md`

## 工程 1. ベースフレーム（井桁）

**部材**: HFS5-2020 L840×4（長手材 rail_L/R_in・out）、L550×6（横材 x=±110/±210/±410 の中央）、L45×4（x=±410 の左右端）

1. 主桁2本（y=±350）と横桁2本（x=±410）で外周 840×720 の矩形を作る。
   ブラケットは**角ごとに2個（表裏）**を基本とする。
2. 内桁2本（y=±285）を通す。⚠ **内桁は外周まで通しきる**こと。
   ここを短く切ると支持経路が切れて骨格全体がぐにゃぐにゃになる（静解析で確認済み）。
3. 車軸横桁2本（x=±300、y=-285..+285）を入れる。
4. **確認**: 対角長 = √(840² + 720²) = 1105.7mm。左右の対角差を **±1mm 以内**に。
   ここの直角が出ていないとメカナムがまっすぐ走らない。

## 工程 2. 走行系

**部材**: M3508 P19 ×4、モーターマウント板 t5 ×4、マウント耳 t4 ×4、ハブアダプタ ×4、メカナム φ100 ×4

1. マウント板に M3508 を **4-M4×14** で留める（J1、締付 2.8N·m）。
   インロー **φ16.7**（工程 0.3 参照。φ26 ではない）が座に入っていることを
   目視で確認。⚠ 斜めに入れると軸が振れる。
2. マウント板 + 耳を、内桁（y=±285）の上面へ **M5×16 ×2** で締める（J2、5.0N·m）。
3. ハブアダプタを出力軸に通し、M3 いもねじで軸の平面を押さえる。
   ⚠ **ねじロック剤（中強度）必須**。ここが緩むと試合中に車輪が抜ける。
4. メカナムホイールをハブアダプタへ **4-M4**。左右で**ローラーの傾きが逆**であることを確認
   （前から見て「ハ」の字と「逆ハ」の字が対角で揃う）。
5. **確認**: 4輪を接地させ、フレーム上面 z=135mm が水平か。ガタは 1mm 以内。

### 工程 2b. 計測輪ユニット（3組）

**部材**（1 組あたり）: 双列オムニ φ50×W20、変換ハブ PETG、φ5 研磨軸、
MR105ZZ ×2、軸受ボス φ14、キャリッジ金具 PETG、取付板 PETG、
リニアガイド MGN9 レール（長さ 64mm）+ MGN9C ブロック、AS5600 基板 + φ6×2 磁石、
輪ゴム #10 ×2（+ 予備）

取付位置は **(X=+210, Y=0)（90° 傾ける）** と **(X=−180, Y=±345)**。
中央の 1 輪だけ転がり方向が Y。⚠ **3 輪を同じ向きに付けると横速度が
原理的に出ない**（DESIGN §38）。向きを間違えたまま組んでも走るので、
組んだ直後に必ず向きを目視で確認すること。

1. 取付板にレールを **3-M3 通しボルト + ナット**で留める（皿座はレール側）。
   ⚠ PETG にタップは立てない（4kgf も掛からずに舐める）。
2. ブロックをレールに通す。⚠ **レールの端から入れて端から出さない。**
   ボールがこぼれると復旧できない。仮の芯棒（付属品）を使う。
3. キャリッジ金具をブロック上面へ **4-M3**。
4. 軸受ボスを金具へ圧入 → MR105ZZ ×2 を突き合わせて圧入 → φ5 軸を通す。
5. 変換ハブを軸へ圧入 + 止めねじ、オムニを **3-M3（PCD22）** でハブへ。
   ⚠ ローラーが**指で軽く回る**ことを確認（渋いと横力を逃がせない）。
6. 磁石を軸端へ接着 → エンコーダ台座 → AS5600 基板を **2-M3**。
   エアギャップは **1.0mm**（0.5〜3mm が AS5600 の推奨）。
7. 取付板を骨格の下面へ **2-M5 溝ナット**。
8. 輪ゴム #10 を上下のピンへ **2 本**掛ける。
   **確認**: ばね秤で車輪を持ち上げ、接地荷重が **7 ± 1N**。
   外れていたら本数を 1〜3 本のあいだで増減する（1 本 ≒ 3N）。
9. **確認**: 車輪を手で押し上げて **8mm** 動き、放すと戻ること。
   機体を持ち上げたとき、キャリッジが**ピン座に当たって止まる**こと
   （レール端まで落ちていたら座の高さが違う）。

## 工程 3. 側面トラス（左右）

**部材**: HFS5-2020 L1037×2（後柱＝マスト主柱）、L703×2（前柱）、L635×2 + L145×2（上桁 topbeam1 / topbeam0）、**HFS5-2010** L707×2（斜材）

⚠ 斜材だけ **2010**（20×10）で、他とは型番が違う。`BOM.md` §1 は型番ごとに
表を分けてある。前は 2020 の表しか出ていなかったので、**この 2 本が発注リストに
1 度も載っていなかった**。

1. 平らな定盤の上で、片側ぶんを**先に平面で組む**（後柱・前柱・上桁・斜材）。
   ⚠ この平面組みを飛ばして立体で組むと直角が出ない。
2. 斜材は両端をガセット板（A5052 t3）で留める。**ガセットの 4 穴のうち
   2 穴は斜材の溝、2 穴は柱／上桁の溝**に入る。⚠ 斜材側の 2 本は
   **斜材の軸線の上**に並ぶ（溝は 1 面に 1 条で、その芯が軸線）。
   後入れナットは斜材を組む前に溝へ入れておくこと（端から入れられる
   のは組み上げる前だけ）。
3. 左右のトラスをベース主桁（y=±350）の上に立て、柱脚を **M5×20 ×2/箇所**で締める。
4. **確認**: 上桁の上面 z=838mm、左右の高さ差 ±1mm。
   グラバーのレールがここに載るので、**左右の平行が出ていないとフォークが斜めに出る**。

⚠ **押出材を1本たりとも省略しないこと。** 部材感度解析（`scripts/frame_optimize.py`）で
全 14 グループを1つずつ抜いて確かめた結果、**削れる部材は無かった**。
特に前柱を省くと砲塔取付面の変位が **7.6 倍（13.1mm）** になる。
上桁・砲塔台座横梁・ベース桁類は抜くと荷重経路そのものが切れる。

## 工程 4. 砲塔台座と旋回体

1. 台座横梁2本（L680、x=125/345）を左右トラスの上に渡す。
2. リングプレート t4 を **8-M5×18**（J5）で横梁へ。Vリング + カムフォロア3個を組む。
   ⚠ カムフォロアの偏心軸で**予圧を調整**する。手で回して「重すぎず・ガタなし」に。
3. 旋回テーブル t6 → 砲塔サイドプレート t5 ×2 → 横梁 の順。
4. ヨー駆動: M3508 + HTD5M 20T、大プーリ 60T をテーブル下面へ。
   ベルト張力は「指で押して 5mm たわむ」程度。
5. **確認**: ヨー ±30° で手回しし、斜路・椅子・マスト・側面トラスのどこにも当たらないこと
   （CADでは干渉ゼロを確認済み。実機で必ず再確認）。

## 工程 5. 射出ユニット（仰角ユニット）

1. 仰角側板 t5 ×2 にローラー軸（φ12 中空）2本を軸受で通す。
2. ローラー（3Dプリントハブ + ウレタンタイヤ t3）を各軸に5個、
   Y = 0, ±130, ±265 で固定。⚠ **軸方向の位置を上下で一致**させる。ずれるとニップが斜めになる。
   ⚠ **ローラーは絶対に軽量化しないこと**（肉抜きを増やさない）。
   回転慣性が 1射あたりの速度降下を 3.5% に抑えており、これが命中率を守っている。
   半分に軽くすると降下が 7.1% になり初速ばらつきが倍になる（`scripts/roller_inertia.py`）。
3. ニップ隙間を **1.5mm** に。**テーパくさび 1:20**（M4×0.7 駆動、分解能 3.5µm）で調整し、
   隙間ゲージで全5点を確認。
   ⚠ 5点の隙間差は 0.2mm 以内、絶対値は ±15µm 以内。
   **ここのばらつきが命中率をほぼ決める**（対策なし26% → 隙間管理で49%、
   さらに射出ごとの初速実測補正で65%。`scripts/accuracy_budget.py`）。
   偏心カムは分解能 209µm で目標の14倍粗いので採用しない。
4. M3508（ギアボックスレス）を **HTD5M ベルト（1:1、軸間85mm）でローラー軸へ**。
   ⚠ **モーターを軸の延長線上に付けてはいけない。**
   軸端は |Y|=310 で、そこに M3508（全長98.4）を付けると先端が **|Y|=408** になり、
   側面上桁（|Y|=340〜360）を**物理的に貫通して組み立てられない**。
   軸を短くしてモーターを内側へ寄せる案も、ローラー最外が |Y|=285 なので成立しない。
   - **上ローラー用**: 軸の**真上**（局所 z = +130.75）。仰角20〜70°での最低点 Z=914.7
   - **下ローラー用**: 軸の**後方**（局所 x = −85）。同 最低点 Z=856.0（台座838まで18mm）
   - モーター中心は **|Y|=250**。上桁340より内側・ローラー285より外側
   ⚠ 下側を真下（−Z）に付けると仰角20°で砲塔台座（838）に潜るので不可。
   → 根拠は DESIGN.md § 34
5. 仰角のウォーム減速機（m1.5・1条・40:1・中心距離 42mm）を組む。**順序を守ること。**
   1. ウォームホイール（z40・歯先φ63・A5052）を、ボス側を側板に向けて
      **6-M4 PCD28** で仰角側板（R）の内面へ。J10 安全率 3.6 = 全締結中で最小。
   2. ウォーム軸（φ12・ねじ部 z±14）に **6001ZZ を 2 個**、軸の鍔に突き当てて入れる。
      鍔は z=24〜28 と z=−26〜−22 の 2 か所。
   3. 軸受ブロック（R 側板内面へ 4-M4）に軸受の外輪を落とし込み、
      **スラストカラーを内輪の外側から締めて軸方向の遊びを取る**。
      ⚠ ここを締め忘れると、ウォームが軸方向に逃げて噛み合いが浅くなる。
      ウォームは**軸方向に 560N（定格）で押される**部品で、径方向より
      軸方向のほうが厳しい。
   4. **中心距離 42.0mm を測る**（ホイール基準円 φ60 とウォーム基準円 φ24 の和 ÷2）。
      ここが 1mm でも違うと歯当たりが片寄る。側板の穴位置で決まるので、
      板を作った時点で確定している。
   5. ウォーム軸と M2006 を **φ8-φ12 カップリング**（いもねじ 各2本）で結ぶ。
      ⚠ **モーター軸を直接ブロックの穴に挿してはいけない**（以前の図はそうなっていた）。
      M2006 の φ8 軸はラジアルもスラストも受けられない。
   6. バックラッシュは **片フランク 0.12mm**（全遊び 0.24mm ＝ 仰角 0.46°）を狙う。
      詰めすぎると噛み込んでセルフロックが「固着」になる。
   ⚠ セルフロックは**進み角 3.576° < 摩擦角 4.868°（μ=0.08）**で成立している。
   **グリス以外（潤滑油・シリコンスプレー）を差さないこと。** μ が 0.059 を
   下回ると自重で仰角が落ちる。
6. 仰角ユニットをニップ中心（X=235, z=900）で砲塔サイドプレートに軸支する。
   ⚠ **仰角軸とニップ中心を一致させる**のが本設計の肝。ここがずれると仰角ごとに射出点が動く。
7. **確認**: 仰角 20°/45°/67°/70° で、雑巾の通り道に構造物が入っていないこと。
   **67° が旗に対する最良解**（gpusim: 初速8.25m/s で命中37%）なので必ず出せること。

## 工程 6. ホッパー・シンギュレータ・斜路

1. ホッパー（A5052 t1.0 板金、内寸 420×620、開口 z=712）を組み、側面トラスへ吊る。
   ⚠ 開口高さ 712mm は **机天板の裏面(742)より30mm低い**必要がある。
   ここを上げると机の下に潜れず、フォークが山に届かない。
2. 底板を **前壁側へ8°** 傾けて取り付ける。
3. **分離ゲートを作る（ここが分離の全て）。**
   1. 前壁の上端を **z=691** で切る（= ローラー最下点 700 − 隙間 5 − パッド 3 − 台 1）。
      ⚠ ここを 712（開口高さ）のまま立ててはいけない。ローラーの窓を開けても、
        窓は幅46×5=230mmしかなく、残る390mmで布が壁に当たって出られない。
   2. 軸受ブロック（A5052、|Y|=305）に **POM フランジブッシュ φ8/φ12** を圧入。
      鍔はホッパーの**内側**へ。中空軸 φ8×t1.5 を通し、分離ローラーのハブ5個を
      **φ2スプリングピン**で固定する（薄肉軸なので止めねじは使えない＝管が潰れる）。
      ウレタンタイヤはハブへ圧入するだけ。**摩耗したらタイヤだけ抜いて替える。**
   3. パッド台（A5052 t1 の U字クリップ）を前壁の上端に**馬乗りで被せ**、
      座金付きリベット 2本で留める。プラダンの切り口には直接貼れない。
   4. シリコンパッド t3 を台へ落とし込んで接着。ローラー真下の5か所だけでよい。
   5. **隙間を実測する**。ローラー最下点とパッド上面で **5.0 ±0.3mm**。
      3mm以下だと1枚目も止まり、6mm以上だと2枚重ねが素通りする。
   ⚠ 摩擦係数の序列 **ローラー > 布間 > パッド > ガイド** を材質で作る。
   ⚠ **満載でないと山がローラーに届かない**（床の前端 592 に対しゲートは 695）。
     圧板（ばね押し上げ）は質量の枠が空くまで入れていない。→ DESIGN.md §3.4
4. モーターは**軸受ブロックの上面**へ PETG 金具で載せ、クランプ式軸継手で直結する。
   ⚠ 側壁（プラダン）に留めてはいけない。中空板に 1.0N·m の反力は効かない。
   ⚠ 継手は軸を **10mm 掴む**まで差し込む。端面を突き合わせただけでは回らない。
5. 斜路（39°、**X=+10,z=700 → X=+84,z=760**）の下面ガイド（幅560）を付ける。
   ⚠ **側板はガイド板の下側に、高さ25mmで付ける**（|Y|=290）。上に立ててはいけない。
   60mm 上向きに立てると Z が 699〜851 に広がり、
   キャリッジ横梁（Y=±313 の全幅・Z764〜767）と砲塔サイドプレート（Z820〜950）の
   **両方に当たる**。布は押さえベルトで上から拘束しているので下側で足りる。
   ⚠ 斜路の出口を **X=84 より前に出さない**。旋回体はヨー±30°で X=94 まで来る
   （静止時の座標 125.6 で判断すると当たる）。→ DESIGN.md § 34
6. 押さえベルト2本（幅50）を張る。M2006 1軸で分離ローラーとベルトを同時に駆動。
7. **確認**: 雑巾を **2枚重ねて**手で山に置き、1枚だけがニップ入口まで届くか。
   10回連続で。2枚出たらゲートの隙間が広い、1枚も出なければ狭い。

## 工程 7. グラバー

1. スライドレール SRX3616 ×2 を、側面トラス上桁の内側（|Y|=350）へ **M4×5/本**（J6）。
   **取付穴は片面5箇所の長穴**（公式CADから実測。`scripts/rail_holes.py`）:

   | 位置 | レール端からの X [mm] | 長穴長 |
   |---|---|---|
   | 両端 | **0〜13**, **362〜375** | 13mm（取付調整用） |
   | 中間 | **23〜28**, **108〜114**, **248〜254** | 5〜6mm |

   ⚠ **等間隔ではない。** 規格表に載っていないので図面から拾うこと。
   上桁は HFS5-2020 なので**ポストナットを溝に入れて長穴に合わせる**。
   長穴の範囲（両端13mm・中間5mm）を超える調整はできない。
   ⚠ **左右の前後位置を 0.5mm 以内で揃える**。ずれるとレールがこじれて動かない。
2. キャリッジ（後端横梁 t3 + 側金具 t5 ×2 + 補強リブ）をインナーレールへ。
   側金具は **|Y|=316**（インナーレール内側面 320.9 より内側）。
3. 傾斜ヒンジ（φ8 中空軸）をキャリッジ前端（X=-15）に通し、櫛歯アセンブリを吊る。
   戻しばねを掛け、**引込み端の固定カム**で 22° 押し下がることを手で確認。
4. 櫛歯（SUS t2.0 ×5、幅20・長さ290・ピッチ110）を根元バーへ **2-M4/本**（J7）。
   ⚠ **櫛歯の下面が机上面 +1mm（z=761）** になるよう、シムで高さを合わせる。
   5mm 浮かせると「山の下」ではなく「1枚目と2枚目の間」に入ってしまう。
   ⚠ **先端30mm のテーパは「上面だけ」を研ぐ**（t2.0 → t0.2、3.4°）。
   フォークリフトのツメと同じで、**下面は水平のまま**にすること。
   下面ごと曲げる（例: 8°）と先端が天板より低くなり、
   机の**縁に正面衝突して机を押す**（ルール 4.1.4a の反則）。
   研磨後、**定盤の上に歯を置いて下面全長がベタ当たりする**ことを確認する
   （すきまゲージ 0.05mm が入らないこと）。
   → 根拠は `scripts/fork_clearance.py` と DESIGN.md § 32
5. 上押さえ（t2 プレート + スポンジ）をガイド軸2本 + ラック&ピニオン（M2006）で。
   ばねで押付力を **25N** に制限。
6. ベルト駆動: 駆動軸 X=+60（M2006）、アイドラ X=-430、|Y|=240、z=845。
   ブラケットは**レール上端 818 より上だけ**を使う（レールは動くので絶対に被せない）。
7. **確認**: 全開（425mm）→全閉を10往復。フォーク先端のふらつき **±1mm 以内**。
   全閉で櫛歯が 22° 傾き、ホッパー開口の真上に来ること。
8. ⚠ **必須実測: 全開時の歯先の下がり。** レールのたわみ＋ガタはカタログに
   記載が無く、この機構で一番効く誤差源（想定 0.60mm）。
   キャリッジを全開にし、**歯先にダイヤルゲージを当てて全閉時との差を測る**。
   - **0.24mm 以下** … 最悪ケースでも 1.0mm の隙間に収まる。問題なし
   - **0.24〜0.9mm** … 縁での伸長 200mm では 0.53mm しか下がらないので実用上は成立。
     ただし机への接近停止位置がずれると余裕が減る。停止精度 ±60mm を守ること
   - **0.9mm 超** … レールのガタが過大。レールを交換するか、
     キャリッジ側金具を長くしてインナーレールの支持スパンを伸ばす
   → 根拠は `scripts/fork_clearance.py` と DESIGN.md § 32

## 工程 8. マスト・移動バケツ

1. 上部横梁（L680）を後柱間に渡す。片持ちビーム2本（L300、|Y|=150）を前へ。
2. バケツ受け板 t3（`fab/dxf/bucket_seat.dxf`）を帯の部分でビームに載せ、
   4-M5 の溝ナットで留める。位置決めタブ 4 個（PETG）を受け板の耳へ 1-M5 ずつ。
   ⚠ DXF に入っている穴は**バケツ固定 4 か所（PCD φ204）とタブ 4 か所
   （PCD φ258）だけ**。溝ナット用の 4 か所は、他の板と同じく現場で
   ビームの溝を基準に罫書いて φ5.5 をあける（凍結した位置は
   `out/screws.json` の `scr_a0038`〜`scr_a0041`）。
3. **バケツに穴をあける**。⚠ ここが唯一の不可逆な工程なので、順序を守る。
   1. バケツ（エンテック PO-24A）をタブの内側へ落とし込む。テーパーで
      自然に芯が出る（タブ内面とのすきま 0.3mm）。
   2. **受け板の φ5.5 の穴 4 か所を治具にして**、下からセンターポンチ
      （またはマーカー）でバケツの底へ位置を移す。ピッチ円 φ204。
      ⚠ 載せたまま穴をあけない。切粉が機体の中へ落ちる。**バケツを外して
      ボール盤で** φ5.5 をあけ、バリを両面から取ること（ポリカは縁から割れる）。
   3. バケツを外し、押さえリング（PETG t4）を**バケツの中**へ入れて、
      M5 皿ボルト 4 本で リング → バケツ底 → 受け板 の順に通し、
      板の下で平座金＋ナットを掛ける。皿頭はリングの座に沈んで面一になる。
      ⚠ ナットは**ナイロンナット**（緩み止め）。走行の振動で緩むと、
      規定 3.2.3a の「常に水平を維持」が崩れる。
   ⚠ **加工も固定も 2L 目盛りより下だけ**（規定 3.2.3c は目盛りより「上」の
   加工を禁じている＝下は可）。中に入れてよいのは押さえリングだけ
   （規定 3.2.3d「固定のみを目的とした部品」）。
   ⚠ 予備のバケツも同じ穴をあけておくこと。受け板を治具にすれば同じ位置に開く。
4. **確認**: バケツ上面の高さ **1430mm**（規定 1200〜2100）。
   機体の最高点が 1191mm で、2L目盛り（約1240mm）より下にあること。
   位置決めタブの上端は バケツ底面 1175 + 16 = 1191mm。
   ⚠ ここは `tr_params.py` の `BUCKET_TOP_Z` / `BUCKET_2L_Z` と同じ値でなければ
   ならない。`scripts/doc_check.py` が突き合わせる（前は 1407/1218 と書いてあり、
   **手順書どおりに測ると 22mm 合わない**状態だった）。
   ⚠ 2L 目盛りの高さ（暫定 65mm）は**買ったら実測**して `BUCKET_2L_FROM_BOTTOM`
   を直すこと。円錐台として体積を積むと 2L は底から 47mm 前後で、暫定値より
   低い可能性が高い。固定金具はいちばん高いタブでも 16mm なので、どちらでも
   規定は満たす。

## 工程 9. 椅子・マスコット・装飾

1. 椅子（新JIS 5号）の脚を切除。**座面・背もたれ・接続部は無加工**（規定 3.1.2）。
2. 座板を電装デッキ（z=135）へ 4点マウント金具で固定。背もたれが **+X 側**。
3. マスコット「シボリ」を座らせ、**正面を -X（補充スポット方向）**に。
   形は `L.mascot_parts()`（DESIGN.md §40）。外形は規定の 300×300×600 に
   ちょうど内接する。作り方:
   - 芯は EPP ブロックから切り出し（体積 19.6L・約 1.2kg）。体・頭・靴の
     3 塊で削り、首の座（φ92）で頭を差す
   - 表面はフェルト張り。つなぎ（藍）と三角巾（赤）は別布で、縫い代を
     内側に折って縫う。三角巾は後頭部で結ぶ
   - 目はボタン（φ52・糸穴 4-φ5）。口は縫い目
   - 胸のゼッケンに**チーム名**を入れる（規定 3.1.3「チームメンバーの
     一員とわかるような服」）
   - 尻に M6 鬼目ナット 2 個を埋め、座板の下から蝶ボルトで留める
   ⚠ 動力・給電は内外とも禁止。電飾のみ可。**蝶ボルトは工具無しで外せる**
   （規定「計量計測時には速やかに取り外せるようにしておくこと」）。
   ⚠ 著作権が絡むキャラクターは使用不可。この造形は雑巾の要素だけで
   起こしてある（絞り目・四隅の耳・絞り終わりのねじり）。
4. 装飾を施す（規定 3.1.4・審査対象）。

## 工程 10. 電装

1. 電装デッキ（t1.5 肉抜き）に バッテリー → 主幹30Aブレーカー → C620×7 / C610×4 → STM32 の順で配置。
2. CAN はデイジーチェーン。**終端抵抗 120Ω を両端に**。
3. 非常停止 ×2（側面トラス上桁 z=838、前 X=+330/Y=+352、後 X=-250/Y=-352）を
   **駆動系の主回路に直列**で入れる。電源表示LEDも点灯確認できる位置に。
4. LiDAR3台（北陽 UST-20LX。前後 z=69.6、上段 z=500）と ToF×2、IMU、カメラを配線。
   ⚠ **検出面は本体の底面から 47.4mm**（中央ではない）。取付座の高さは
   これで決まっているので、別機種に替えるときは必ず外形図を見ること。
   本体は座に **2-M3（ピッチ40・深さ6）** で留める。
   ⚠ **LiDAR は 3 台とも下向きに吊ってある。** 本体は可動板の下面に
   2-M3 で留める（座は本体の上）。
   下段の配線は**レベリング座の φ40 の穴を真上から**通す（板の外を回すと、
   傾けたとき配線が突っ張って傾きを戻す向きに効く）。上段は本体の下面が
   開いているので、そこへ下から挿す。
5. **確認**: 非常停止を押して**全モーターが確実に止まる**こと。無線断でも停止すること。

### 工程 10b. LiDAR の水平出し（3台・レベリング座）

走査面が 1° 傾くと 5m 先で 87mm ずれる。**切削と組立の公差だけでは
0.5〜1° 残る**ので、ここは必ず実測して追い込む。目標は **0.2° 以下**。

用意するもの: デジタル角度計（分解能 0.05° 以上）、M4 六角レンチ、
M4 スパナ（戻り止めナット用）、平らな床または定盤。

1. **機体そのものの姿勢を先に確定する。** 平らな床に置き、ベースフレームの
   上面（デッキ座面）へ角度計を当てて前後・左右の傾きを控える。
   ⚠ ここを飛ばすと、機体の傾きを LiDAR 側で打ち消してしまう。
   合わせるのは**機体基準**であって水平ではない（走行中は傾く）。
⚠ **前の下段 LiDAR は、椅子を載せる前に済ませること。** 調整ねじ 4 本の
うち -X 側 2 本と、固定板を横材へ留める 2-M5 は座板（X≤460）の真下に来る。
椅子は 4-M6 で外せるので、順序さえ守れば工具は入る。

2. 4 本の調整ねじ（M4×30）を、**ばねが少し縮む程度**まで均等に締める。
   ねじの頭は**固定板の上面**（いちばん上）。可動板の下に出た先端が 8mm ／
   2 枚の板のすきまが 12mm のあたりが中立。
   ⚠ 締めると LiDAR が**上がる**（可動板ごと引き上げられる）。緩めると
   ばねが押し下げる。載せる形とは向きが逆なので注意。
3. 角度計を LiDAR の上面（走査窓の上のフラットな面）に載せ、
   **X 方向（前後）** と **Y 方向（左右）** の 2 姿勢で読む。
4. 下がっている側の 2 本を緩める / 上がっている側の 2 本を締めて追い込む。
   **M4 の 1/12 回転（時計の 1 時ぶん）で 0.076°**。
   ⚠ 4 本を同時に回さない。対辺 2 本ずつ、1 軸ずつ決める。
   ⚠ 4 点は過拘束なので、**締めすぎると板がたわんで角度計が嘘をつく**。
   ばねが密着（すきま 9mm 以下）したら締めるのをやめ、反対側を緩める。
5. **確認**: 両軸とも 0.2° 以内。到達したら可動板の下に出たねじ先へ
   M4 ナットを掛け、**レンチでねじ側を押さえながら**ナットを締める
   （ねじが供回りすると角度が動く）。締めた後にもう一度読み直す。
6. **実測で裏を取る**: 平らな壁から 3m の位置に機体を置き、LiDAR の点群で
   壁が直線に出るか、距離が全周で一定かを見る。下段は床（z=0）や
   机の天板（z=700）を拾っていないことも確認する。
